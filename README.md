# MyTool
A software to automate a computer. <br>
It’s designed for Windows only.

## Functions
### Delete all screenshots
Deletes all files in the default screenshots folder on Windows.
### Clean up Downloads
Groups all files in the default downloads folder on Windows by their file extension and move them in folders.
### Clean up Desktop
Groups all files on the desktop on Windows by their file extension and move them in folders.
### Empty Recycle Bin
Clears the recycle bin.
